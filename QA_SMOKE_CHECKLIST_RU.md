# QA Smoke Checklist (RU)

## 0) Подготовка
1. Открой `Settings` -> `Language` и выбери русский.
2. Разреши уведомления для приложения в iOS.
3. В приложении включи:
   - `Уведомления capture`
   - `Подтверждения автосписаний`
   - `Напоминания о долгах` (опционально для проверки reminders)
4. Подготовь данные:
   - минимум 1 счет с положительным балансом
   - минимум 1 долг с `Минимальный платеж > 0` и `День платежа <= сегодня`
   - для негативного кейса: отдельный долг с платежом больше доступного баланса

## 1) Capture / Apple Pay flow
1. Открой `Settings` -> `Capture & Shortcuts` -> `Запустить тест capture`.
2. Проверь push:
   - заголовок: `Добавить платеж` (для shortcut/deep link)
   - тело содержит merchant/amount и `Нажмите, чтобы добавить платеж`
3. Тапни push.
4. Проверь, что открылась `Quick Add` с предзаполненными данными.
5. Сохрани транзакцию.
6. Ожидаемо:
   - транзакция появилась в истории
   - на главной в `Последние операции` она отображается корректно

### Вариант Apple Pay source
1. Запусти deep link с `source=apple_pay`, например:
   `financeapp://capture?amount=1990&merchant=Test%20Store&currency=KZT&source=apple_pay`
2. Ожидаемо:
   - заголовок push: `Платёж Apple Pay получен`
   - тело содержит `Нажмите, чтобы добавить платеж`

## 2) Автосписание долгов (успешный кейс)
1. Создай/открой долг:
   - `Минимальный платеж` меньше или равен балансу выбранного счета
   - `День платежа` = сегодня или раньше
   - `Счёт автосписания` выбран (или `Счёт с наибольшим балансом`)
2. Полностью закрой приложение и открой снова.
3. Ожидаемо:
   - добавлена расходная транзакция с заметкой вида `Автосписание долга: <название>`
   - остаток долга уменьшился
   - пришло уведомление:
     - `Платёж по долгу добавлен` (1 долг), или
     - `Автосписаний по долгам: N` + `Автосписано всего: ...` (несколько)

## 3) Автосписание долгов (недостаточно средств)
1. Для второго долга поставь `Минимальный платеж` больше доступного баланса счета.
2. Убедись, что `День платежа <= сегодня`.
3. Перезапусти приложение.
4. Ожидаемо:
   - новая расходная транзакция по этому долгу НЕ создается
   - остаток долга НЕ меняется
   - уведомление: `Обновление автосписаний по долгам` и `Пропущено (недостаточно средств): ...`

### Проверка анти-дублей
1. Повтори перезапуск приложения несколько раз в том же месяце.
2. Ожидаемо:
   - повторных списаний/уведомлений для уже обработанного цикла нет

## 4) Автосписание долгов (недоступный счет)
1. Задай долг с невалидным автосчетом (например, удаленный счет) или оставь автовыбор при нулевых/отрицательных балансах всех счетов.
2. Перезапусти приложение.
3. Ожидаемо:
   - платеж не создается
   - уведомление содержит `Пропущено (счёт недоступен): ...`

## 5) Локализация RU (регресс)
1. На главной проверь:
   - заголовок блока: `Регулярный денежный поток`
   - в `Insights` есть карточки `ПЛАТЕЖИ` и `ДОХОД`
2. В аналитике проверь:
   - `Доходы по категориям`
   - `Топ источников дохода`
3. Открой долг и проверь поля:
   - `Счёт автосписания`
   - `Счёт с наибольшим балансом`
4. Ожидаемо:
   - в этих сценариях нет английских строк

## 6) Быстрый автоматический прогон (что уже сделано)
1. `xcodebuild -project FinanceApp.xcodeproj -scheme FinanceApp -destination 'generic/platform=iOS' build` -> `BUILD SUCCEEDED`.
2. Запуск UI-тестов на `iPhone 16` не прошел (нет такого симулятора в окружении).
3. Запуск на `FinanceApp Test iPhone 16e` был прерван вручную после сборки (раннер завис без финального отчета), поэтому functional-часть подтверждается ручным чеклистом выше.

## 7) Локализация (авто-проверка)
1. Проверка паритета ключей локализаций:
   - `./scripts/check-localization-parity.sh`
   - Ожидаемо: `Localization parity OK for: en ru kk`
2. Локализационный preflight встроен в iOS-скрипт:
   - `./scripts/test-ios.sh build`
3. Точечный UI smoke для RU:
   - `./scripts/test-ios.sh ui FinanceAppUITests/FinanceAppUITests/testDashboardWeeklyBudgetLocalizedInRussian`
   - `./scripts/test-ios.sh ui FinanceAppUITests/FinanceAppUITests/testCalendarScreenLocalizedInRussian`
4. Если симулятор падает с `Mach -308`, повторить прямым `xcodebuild`:
   - `xcodebuild -project FinanceApp.xcodeproj -scheme FinanceApp -destination 'platform=iOS Simulator,name=FinanceApp Test iPhone 16e' -only-testing:FinanceAppUITests/testDashboardWeeklyBudgetLocalizedInRussian test`
   - `xcodebuild -project FinanceApp.xcodeproj -scheme FinanceApp -destination 'platform=iOS Simulator,name=FinanceApp Test iPhone 16e' -only-testing:FinanceAppUITests/testCalendarScreenLocalizedInRussian test`
